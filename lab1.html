OWASP A06:2025 · Insecure Design CWE-434

What is unrestricted file upload?

A portal has unrestricted file upload (CWE-434) when it accepts dangerous file types its workflow should reject. Here, missing upload rules make it an example of OWASP A06:2025 Insecure Design. Unsafe processing after acceptance can turn a bad upload into a wider incident.
