How every lab works

The same three moves, in the same order, on every page.

1

Read the bug

Short code, one highlighted line. You see exactly which line causes the problem and why.

2

Press a payload

Pick a payload button on the vulnerable version and watch the effect on the simulated page.

3

Switch to the fix

Press the same payload on the fixed version. It is blocked, and you see which line stopped it.

What is on each lab page

  1. What it isPlain English, with the OWASP category and CWE.
  2. The lineRealistic code with the buggy line highlighted.
  3. Try itPayload buttons and a live simulation.
  4. Why it mattersThe damage, and a real incident when we found one.
  5. The fixFixed code, with the same payload now blocked.
  6. SourcesWhere to read more.
