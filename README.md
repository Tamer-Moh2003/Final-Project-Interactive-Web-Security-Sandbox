# Ghurir – Interactive Web Security Sandbox

**42 Irbid | Cybersecurity Final Project – November 2026**

## Project Overview

An interactive web security sandbox featuring three hands-on labs. Each lab demonstrates a simulated security vulnerability, its potential impact, and a working fix that blocks the same payload.
